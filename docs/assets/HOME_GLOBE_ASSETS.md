# Home globe image sources

The home globe uses locally served images so the landing page does not depend on a live photo search. These images are visual inspiration. The scene markers are approximate coordinates and do not mark verified itinerary stops.

The Pexels images were downloaded as 960 × 640 compressed JPEGs on 2026-10-29. The [Pexels license](https://www.pexels.com/license/) permits use on websites and apps. The globe UI links each image to its photo page and credits the photographer. NASA [media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/) asks for credit and prohibits implied endorsement; the UI credits NASA Earth Observatory.

If a scene photo or its location text is changed, verify the photo's page and location before shipping. The card title names the broader region, not a precise photographed viewpoint. Do not use these images to assert route verification or a bookable offer.
